# 💼 Portfólio Escolar — Desenvolvimento de Sistemas

Um portfólio web criado para reunir projetos desenvolvidos durante o curso técnico em Desenvolvimento de Sistemas e apresentar essas atividades em uma interface visual organizada.

## 📖 Sobre o projeto

O **Portfólio Escolar** funciona como uma vitrine dos projetos realizados ao longo dos estudos. A página apresenta projetos em destaque, imagens ilustrativas e links para os repositórios e demonstrações online.

## ✨ Funcionalidades

- 📁 Apresentação de projetos escolares.
- 🔗 Links para repositórios no GitHub.
- 🌐 Links para demonstrações online de projetos.
- 🖼️ Imagens de prévia dos trabalhos.
- 🎨 Layout personalizado e responsivo.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilos e layout.
- **Google Fonts:** tipografia personalizada.

prjPortfolio/

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/prjPortfolio.git
   ```
2. Entre na pasta:
   ```bash
   cd prjPortfolio
   ```
3. Abra o arquivo `index.html` no navegador.

## 🎯 Objetivo de aprendizagem

Praticar a criação de uma página de portfólio, organizar projetos em uma interface clara e conectar páginas web a repositórios e demonstrações externas.
